# 图灵AI学伴

一套 Expo React Native 客户端，使用统一入口提供学生、老师、家长三个体验视角，支持 Web 预览，并保留 iOS 和 Android 客户端结构。

## 启动

```sh
npm ci
npm run web
```

开发预览地址为 `http://localhost:8081`。第一课录屏从`/demo`进入。稳定静态预览可以运行`npm run build:web`后运行`node scripts/serve-preview.mjs`，地址为`http://localhost:4173/demo`。手机原生客户端开发可运行 `npm start`，按 Expo 的设备流程打开。尚未创建商店项目、签名、EAS 项目或可安装的 APK/IPA。

## 当前可以体验

- 1—2、3—4、5—6、7—9年级各16课大纲，共64课，可切换学段和搜索主题。
- 一至二年级第一课讲授版v2：17页大屏、三段科普短片、两次集体回应、一次10分钟作品任务。四段回看和三题练习移至课后自愿使用。
- 图灵老师：本地预设演示对话、快捷提问、设备中文朗读。不调用模型API。
- 作品：画板/照片/文字原稿 → Mock AI生成绘本或彩铅图 → 添加小熊朋友 → 选最终作品。保留原稿和最多4个版本，老师/家长可对照查看。
- 老师：17页大屏课堂、持续动画角色、实际计时、Web固定中文女声、自动翻页与暂停续播、章节跳转、预制对话揭示和小兔/小熊分支、课堂完成标记、本机作品任务和评语。
- 家长：基于本机真实操作的学习记录和作品评语，不预填成绩或学习时长。
- Web备课资源：第一课PPT、教案与逐字稿、单页学生任务单、Syllabus与录屏路线。
- 演示导览：课堂、作品保存、老师点评、家长记录、课后Mock对话，按顺序录制约3—5分钟。

## 数据与演示边界

身份选择是演示导航，不是真实登录、权限隔离或家长绑定。三个角色共用这台设备上的一份虚构学生体验记录。记录通过有版本校验的 AsyncStorage 保存在本机，不上传、不跨设备同步。

当前应用不适合收集真实学生身份、联系方式、位置或其他敏感资料。相册选择只在主动点击时开启，不请求摄像头、麦克风或联系人。作品最多保存12件，每张照片编码后上限约1.5MB；设备存储失败会提示重试。绘画和图片不要含真实学生个人资料。

除第一课外，其他课次目前是课程大纲，不能被标记为已完成。第一课支持老师在课堂结尾标记完成，来源记为`classroom`，不编造答题成绩。课后自愿练习只有三题全对才能以`quiz`来源记录完成。家长页区分两者，回看不会清空已完成记录。

对话明确显示“演示对话”，使用关键词路由到预设示例。真实模型、语音识别、云端账号、机构隔离、支付与推送都未接入。Web课堂使用预先生成的晓晓女声MP3；原生端和普通对话仍使用设备TTS，实际声音取决于设备。固定图片与配音运行时不调用模型。

大屏课堂沿用本项目PPT页面，配叠加的图灵动画。部分设备显示静态角色。Web提供科普中国原站嵌入播放器，第1、6、4集均已试播并确认进度前进，预算分别为3:12、3:10、2:58，总9:20。完整内容适龄审看与教室网络测试仍需课前完成，播放前关闭弹幕。课堂点击一次“开始连续播放”后自动播配音并按计划停留时间翻页；配音结束仍保留看图、回应和画画时间。短片页先播简短引导，再自动加载原站播放器（使用官方p分集参数与autoplay），图灵形象留在右侧。远程跨域播放器不提供可靠的结束/缓冲事件，因此按源片长计时切页；缓冲或浏览器拦截时需暂停并重播本页。暂停后从课堂计时位置恢复远程视频，可能需手动对齐实际进度。本机视频按真实结束事件切页。三段引导语约增加21秒，完整自动流程约40分钟。七分钟绘画倒计时结束自动继续，结尾仍需老师确认课堂完成。

没有下载或打包第三方视频，也没有声明获得再分发许可。可切换图卡讲解，或选择已有使用许可的本机视频临时播放，文件不上传、不持久保存。PPT包含来源超链接与配音备注，没有视频或音轨内嵌；视频和图灵同时出现请用App课堂。

当前代码原型不依赖Zion账户，后续可按实际搭建平台迁移课程数据。未部署公网或改动任何已有站点。

npx expo-doctor
npm run build:web
npx expo export --platform ios --platform android --output-dir dist-native

`dist`为Web静态导出。部署时需为所有应用路由配置回退到`index.html`，保留`/resources`静态文件。这里没有部署到Vercel或其他云平台。

## 初步展示与录屏

已准备`../交付/图灵AI第一课_Web展示包.zip`，只包含构建后静态站点，不含源码、密钥或本机学习记录。解压后把含`index.html`的整个文件夹放到Netlify Drop，可生成分享链接。已附`_redirects`单页应用回退规则。也可使用Vercel等静态托管，需单独配置路由回退；尚未创建或绑定任何托管项目。

别人访问后，每个浏览器独立保存自己的体验记录，不能让老师和家长在不同设备同步查看。完整录屏请在同一个浏览器切换身份。详见`public/resources/demo-guide.html`。

验证记录见 `docs/verification.md`，打包与主体未确认项见 `docs/release-ledger.md`。

## 正式使用前的必要工作

接入真实身份和服务端角色权限、监护人流程、学生与组织绑定、云端存储、同步及备份；确定模型服务和额度后才接真实AI。当前依赖审计仍有上游问题，需在正式打包/部署前按上游修复版本复核，不能直接将演示身份切换当成正式权限方案。

## 固定配音与Mock作画

`public/audio/lesson-01-01.mp3`至`17.mp3`为17页固定女声配音，`voice-preview.mp3`可在演示入口试听。离线播放已缓存/已打包的配音不发生实时模型费用；外链科普短片仍需网络。可用本地Python环境安装`edge-tts`后运行`scripts/build-voice.py`重新生成，声音为`zh-CN-XiaoxiaoNeural`、rate +5%、pitch +6Hz，无运行时密钥。音色听感请使用试听确认。

`assets/mock`包含3张预制月亮花园图。创作室明确标注固定主题，修改文字不实时改变画面；生成等待仅模拟流程，不假装识别草图。正式版应由图片API替换素材选择逻辑。重新选择最终版本会清空旧评语并等待重新点评，避免评语与作品不对应。


## 3—5分钟录屏快速模式

打开`/demo`，点击“进入快速演示（3—5分钟）”，默认4分钟，另可选3或5分钟。点“开始自动演示”后依次展示课堂缩时预览、自动绘制虚构原稿、Mock绘本出图、添加小熊朋友并选择最终图、自动填写/保存示例点评、家长查看。支持暂停续播、跳到任一环节、下一环节、从头重录；暂停时可编辑示例点评，家长页展示同一条文本。

这是独立的录屏演示会话：没有读取或写入AsyncStorage，不改变普通课堂的身份、作品或学习进度。草图、生成版本、最终选择与点评使用同一份领域数据结构，图片仍为固定预制图。完整40分钟课堂入口保持在`/classroom`，第一课2400秒教学计划未改变。

4分钟安排：课堂90秒、草图30秒、出图25秒、修改25秒、点评30秒、家长40秒；3/5分钟按比例缩放。快速课堂只展示原17页图卡，外链科普短片留在正常课堂播放。6段固定女声音频位于`public/audio/quick-demo-*.mp3`；3分钟模式语音播放速度1.08倍。快速流程不计为40分钟学习记录。

`tsconfig.json`启用`allowImportingTsExtensions`，便于Node直接运行TypeScript领域测试；应用仍由Expo Metro打包，无新增运行时依赖。
